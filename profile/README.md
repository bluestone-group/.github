# BLUESTONE GROUP (블루스톤그룹)

> 기업의 디지털 혁신과 소비자 중심의 커머스 혁신을 이끄는 디지털 비즈니스 플랫폼

블루스톤그룹(BX)은 기업의 구매, 마케팅, 상품개발 업무를 맡아 처리하는 **BPO 사업**과,
누구나 IP 굿즈를 만들고 판매할 수 있는 **콘텐츠 커머스 플랫폼**을 운영합니다.
2013년 블루스톤익스체인지로 출발했으며, 서울 상암 DMC에 있습니다.

## 계열사

| 회사 | 하는 일 |
| --- | --- |
| **블루스톤그룹** (BG) | 지주회사. 계열사에 IT 서비스를 제공합니다 |
| **블루스톤익스체인지** (BE) | 구매 BPO. 기업의 소모성 자재(MRO) 구매를 대행하고 B2B 커머스 플랫폼을 운영합니다 |
| **블루스톤커넥트** (BC) | 상품개발 BPO와 IP 콘텐츠 커머스 플랫폼 **굿즈베이커리**를 운영합니다 |
| **블루스톤마케팅** (BM) | 마케팅 BPO |
